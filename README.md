**Platform engineering reference** &nbsp; `Terraform` `OIDC` `Argo CD` `Cosign` `Kyverno` `Prometheus` `OpenCost`

An inspectable design for platform provisioning, short-lived identity, signed delivery, admission/runtime security, reliability, cost visibility and recovery — with CI checks and separately documented runtime evidence.

| **Demonstrated** | **Designed, not yet deployed** |
| :--- | :--- |
| Public CI plus historical **local kind** tests: Argo reconciliation, Kyverno admission, Prometheus, Falco, Trivy, VPA/OpenCost, Velero restore and controlled game days. | AWS bootstrap, live EKS, AWS-backed state/OIDC and multi-region failover. **No active AWS environment is claimed.** |

> **Evidence boundary:** The temporary local test cluster was decommissioned after testing. Published results are historical verification, not a currently running service.
